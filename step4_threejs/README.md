# 4단계: Three.js 기반 3D 캐릭터 및 실시간 리타겟팅

## 개요
- 2단계(비전 엔진)의 관절 데이터를 3D 공간의 아바타 움직임으로 변환
- 3단계(번역 엔진)의 SLM-RAG 결과를 시각화하는 인터페이스 통합
- 교육용 가이드 영상을 PIP(Picture-in-Picture)로 제공

## 주요 기능
### 1. 3D 아바타 시스템 (`avatar.js`)
- **모델**: 전 연령층에 친숙한 중립형 인간 모델(Xbot) 사용
- **렌더링**: WebGL 기반 고해상도 렌더링 (그림자, 안개, 조명 효과)
- **보간(Lerp)**: 데이터 전송 지연 시에도 부드러운 움직임을 보장하는 선형 보간 로직 적용

### 2. 리타겟팅 엔진 (`retargeting.js`)
- **Bone 매핑**: MediaPipe의 손가락 마디 좌표를 3D 캐릭터의 Skeleton 구조에 자동 매핑
- **벡터 연산**: 관절 간의 상대적 거리와 각도를 분석하여 자연스러운 손동작 구현

### 3. 하이브리드 번역 UI 시뮬레이션 (`pip_player.js`)
- **2트랙 시각화**: 
    - **1차 (SLM)**: 기기 로컬에서 즉각적으로 나오는 예측 텍스트 표시
    - **2차 (RAG)**: 서버로부터 도착한 최종 보정 텍스트로 자동 업데이트
- **PIP 플레이어**: 교육용 수어 샘플 영상을 우측 상단에 배치

## 사용 방법
1. 브라우저에서 `step4_threejs/frontend/index.html` 파일을 엽니다.
2. 화면 중앙에 3D 캐릭터가 로드됩니다.
3. 하단 패널에서 SLM 예측과 RAG 보정이 실시간으로 일어나는 과정을 확인할 수 있습니다.
4. 우측 상단의 PIP 영상을 통해 실제 수어 교육 자료와 비교가 가능합니다.
